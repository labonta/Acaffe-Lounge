# Acaffe Lounge — демонстрационный сайт

Одностраничное коммерческое предложение для ресторана в Перми. Готовые статические файлы на HTML5, CSS3 и обычном JavaScript. Установка, сборка, приложение и сервер для просмотра не нужны. Репозиторий демонстрации: https://github.com/labonta/Acaffe-Lounge .

## Как открыть

1. Откройте папку проекта.
2. Дважды нажмите `index.html` или выберите «Открыть с помощью» → уже установленный браузер.
3. Для передачи владельцу скопируйте `index.html`, папки `css`, `js`, `assets` и пустой файл `.nojekyll` вместе, сохранив структуру. Не передавайте один HTML без остальных файлов.

Собственные стили, фотографии и функции доступны без интернета. Встроенная Яндекс Карта требует подключения к интернету. Телефон, карты и социальные страницы используют внешние приложения или интернет. Обычный компьютер может предложить выбрать приложение для звонка — сайт не совершает звонок самостоятельно.

## Что работает

- Якорная навигация, закреплённая шапка и мобильный бургер без текстовой надписи. По нажатию открывается боковая панель; работают Escape, фон-затемнение и удержание фокуса.
- Подписи под фото интерьера. Галерея с увеличением, видимыми стрелками, стрелками клавиатуры, Escape и возвратом фокуса; текстовых подсказок нет.
- До четырёх блюд в каждой категории; для более длинной категории отдельная кнопка «Посмотреть все…». Общей кнопки раскрытия/сворачивания нет. Для текущих данных сначала видны 18 из 22 позиций; ещё четыре салата раскрываются по запросу.
- Категории с отдельными заголовками, выбор таба и активное состояние. Поиск удалён по просьбе пользователя. Все 22 блюда имеют собственные фотографии; подтверждённые компоненты указаны под названиями.
- Бронирование по проверенному телефону, контакты, недельное расписание, переходы на карту и социальные страницы.
- Доступная базовая версия при отказе JavaScript: текст, навигация, телефон, все 22 блюда и ссылки на фотографии.

Корзина, оплата, отправка заявок и подтверждение бронирования не предусмотрены. По прямому запросу пользователя добавлен официальный iframe Яндекс Карт. Собственной аналитики, рекламных скриптов и сторонних обработчиков форм нет; содержимое и сетевые обращения виджета контролирует Яндекс.

## Как обновлять

- Тексты, адрес, телефон, расписание и блюда находятся в `index.html`. Ищите нужный текст обычным редактором UTF-8. Телефон меняйте во всех видимых надписях и ссылках `tel:`.
- Блюдо — элемент `<article class="dish">`. При редактировании названия или состава обновите также `data-search`, при смене категории — `data-category`. Категория должна совпадать с `data-filter` соответствующей кнопки. Не добавляйте непроверенные ингредиенты или аллергены.
- Блюда сгруппированы в `.menu-group` внутри `#menu-groups`. В каждой группе есть `.menu-grid` с уникальным `id` и кнопка `.menu-more` с соответствующим `aria-controls`. JavaScript показывает до четырёх карточек и выводит кнопку только при наличии остальных; количество считается автоматически. Если добавляется категория, добавьте её таб с совпадающим `data-filter`. Без JavaScript доступны все позиции.
- Оформление и адаптивные правила — `css/styles.css` и `css/refinements.css`. Последний содержит доработки второй версии. Палитра и размеры заданы переменными в начале файла.
- Поведение — `js/main.js`. Файлы подключаются обычным `defer`, без модулей и загрузки JSON. Файл `docs/menu-source.json` — архив источника, сайт его не загружает.
- Изображения — `assets/images`. Используйте простые имена строчными латинскими буквами, указывайте размеры и правдивые альтернативные описания. Для новых фото галереи добавьте ссылку с `data-gallery` и `data-caption` по существующему образцу. Атрибут `data-caption` используется как альтернативное описание большого снимка; видимая подпись карточки задаётся в `figcaption`.
- Шрифты — системные Georgia и Arial с системными заменами. Файлы шрифтов не распространяются и не скачиваются. Оформление может немного различаться на других устройствах.

Логотип в шапке и бронировании заново нарисован плавными кривыми SVG по образцу из карточки ресторана. Растровых вставок, пиксельной трассировки и внешних шрифтов в нём нет. Это ручная адаптация, а не полученный от владельца мастер-файл. Все сведения о происхождении фотографий и фактах находятся в `CONTENT_SOURCES.md`.

## Перед реальной эксплуатацией

Получить согласие владельца на содержание и название сайта; подтвердить актуальные блюда, цены, расписание, условия банкетов и доставки. Согласовать право на использование каждой фотографии: наличие фото на Яндекс Картах само по себе не даёт коммерческой лицензии. Запросить оригиналы фотографий, фото остальных блюд, актуальное полное меню и фирменный логотип, если он есть.

В карточке меню есть пометка «Давно не обновлялось». По просьбе пользователя предупреждение убрано из интерфейса, но актуальность цен по-прежнему не подтверждена. До реального запуска сверить цены с владельцем. Ссылка ВКонтакте проверена по адресу в карточке; просмотр самой страницы инструментом был заблокирован. Перед публикацией открыть её вручную и убедиться, что она действующая.

Демонстрация содержит `<meta name="robots" content="noindex, nofollow">`. Это просьба поисковикам не индексировать, а не ограничение доступа. Для согласованного рабочего сайта решение об индексации принимается отдельно.

## Размещение на GitHub Pages

Публикация выполняется по запросу пользователя в репозиторий `labonta/Acaffe-Lounge`. Источник GitHub Pages — ветка `main`, папка `/ (root)`. Установка зависимостей и компиляция не требуются.

1. В корне репозитория находятся `index.html`, `.nojekyll`, папки `css`, `js` и `assets`. Документацию можно сохранить рядом. Служебную папку `review` и исходное задание публиковать не требуется.
2. В настройках репозитория GitHub открыть Pages, выбрать публикацию из ветки и папку `/ (root)` выбранной ветки. Сборка и собственный GitHub Actions не нужны.
3. После выдачи GitHub публичного адреса проверить уже опубликованный сайт на телефоне и компьютере, включая изображения, меню, телефон, социальные ссылки и карту.

Пути относительные и работают под каталогом проекта GitHub Pages. Учётная запись, домен и репозиторий в коде страницы не зафиксированы. Последующие изменения публикуются обновлением файлов в ветке `main`.

## Проверка в этой работе

Пройдены статические проверки разметки, локальных путей, 22 блюд и синтаксиса JavaScript. В браузере проверены категории, раскрытие блюд, галерея, мобильное меню и раскладки 375, 768, 1440 пикселей. Отчёты и скриншоты хранятся локально и в репозиторий не включены. Для согласованной браузерной проверки временно использовался установленный Python и сервер только на `127.0.0.1`. Это средство проверки, а не часть сайта. Встроенный браузер блокирует `file:`; прямое открытие локального файла в нём не проверено. Исходники специально не используют функции, требующие HTTP.

Архив названий, цен, весов и точные источники фотографий находятся в `docs/`. Служебные страницы проверки и первоначальное задание исключены из публикации.
